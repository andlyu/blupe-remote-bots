PATH STUDIO

From sketch to motion.

  1. Prompt. Try “draw a heart”. Heart, star, circle, square, triangle and infinity are built in. In Simulation, Verify & draw checks the full motion and starts playback.
  2. Draw. Click or drag on a plane, switch planes to add depth, or edit XYZ fields in millimetres.
  3. Verify. Simulation uses the same Python planner as real execution: calibrated spacing, joint limits, workspace, speed, tool orientation, closed grippers and swept CAD clearance. Together mode starts the arms at opposite shape endpoints and traces both halves at once. If needed, a bounded outward adjustment keeps the grippers apart; the preview reports the deviation. Together accepts up to 25 mm of measured target error only when the measured posture still passes closed-gripper and CAD clearance checks. Take turns retains strict sequential strokes. Alignment and approach are included; only drawing phases leave a trace.
  4. Inspect. Orbit, pan or zoom; pause, scrub or replay. Save verification exports the model-check receipt.
  5. Run. Real arms mode reads measured joints and live cameras. Run on real arms explicitly joins the API queue as your saved name/email. Stop cancels your own session.

Simulation starts from the documented reference pose with fully open grippers, using read-only API calibration and saved controller safety profiles. It never creates a control session. Real execution replans from fresh measured joints and retains gateway validation. The local CAD model covers original YAM arms, installed grippers and the nominal table; dynamics and movable objects are not modeled. A disabled station must be initialized separately. Robo-house uses the API's 620 mm spacing; YAM1 uses 500 mm. No controller calibration is changed.
